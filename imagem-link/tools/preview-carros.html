⚙ GitHub
Os arquivos enviados do PC vão pro seu próprio repositório do GitHub (grátis). O repositório e a chave ficam só neste navegador: não vão pra sala nem pros outros jogadores. Uma vez só:
  1. No GitHub, crie um repositório público (ex.: owlbear-imagens) com Add a README file marcado.
  2. Abra Fine-grained token, dê um nome e uma validade.
  3. Repository access: Only select repositories → esse repositório.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copie e cole abaixo junto com o nome do repositório.
