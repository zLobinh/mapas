⚙ Chave do GitHub
Pra enviar arquivos do PC pro seu repositório, a extensão usa uma chave do GitHub que fica só neste navegador (não vai pra sala nem pros outros jogadores). Pra criar:
  1. Abra github.com → Fine-grained token.
  2. Dê um nome (ex.: Owlbear) e uma validade.
  3. Repository access: Only select repositories → o repositório mapas.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copie e cole aqui.
Onde hospedar imagens pesadas
  • Enviar do PC (acima): manda pro seu repositório do GitHub sozinho. Até ~95 MB por arquivo.
  • GitHub Pages (grátis): crie um repositório público, suba as imagens e ative o Pages em Settings → Pages. O link fica https://seu-usuario.github.io/repositorio/mapa.webp. Até 100 MB por arquivo. Link de arquivo do github.com (/blob/) é convertido sozinho.
  • Imgur: use o link direto (i.imgur.com/....png).
  • Google Drive: o arquivo precisa estar "qualquer pessoa com o link". O link de compartilhamento é convertido sozinho, mas o Drive às vezes bloqueia; a prévia avisa.
  • Dropbox: o link de compartilhamento é convertido sozinho.
  • Links do Discord expiram em poucas horas: não use.
  • Prefira WEBP ou JPG. Até ~8000 px de lado aparece em quase todo PC; acima de 16384 px muitas placas de vídeo não mostram.
