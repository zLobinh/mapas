⚙ Chave do GitHub
Pra enviar os carros pro seu repositório, a extensão usa uma chave do GitHub que fica só neste navegador (não vai pra sala nem pros outros jogadores). Pra criar:
  1. Abra github.com → Fine-grained token.
  2. Dê um nome (ex.: Owlbear carros) e uma validade.
  3. Repository access: Only select repositories → o repositório mapas.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copie e cole aqui.
