Onde hospedar imagens pesadas
  • GitHub (o mesmo esquema da PMP Fichas): crie um repositório, suba as imagens e ative o Pages. O link fica https://SEU-USUARIO.github.io/REPO/mapa.webp. Até 100 MB por arquivo. Link de arquivo do github.com (/blob/) é convertido sozinho.
  • Imgur: use o link direto (i.imgur.com/....png).
  • Google Drive: o arquivo precisa estar "qualquer pessoa com o link". O link de compartilhamento é convertido sozinho, mas o Drive às vezes bloqueia; a prévia avisa.
  • Dropbox: o link de compartilhamento é convertido sozinho.
  • Links do Discord expiram em poucas horas: não use.
  • Prefira WEBP ou JPG. Até ~8000 px de lado aparece em quase todo PC; acima de 16384 px muitas placas de vídeo não mostram.
